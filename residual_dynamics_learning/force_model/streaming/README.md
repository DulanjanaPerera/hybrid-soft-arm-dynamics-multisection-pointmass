# Streaming generalized-force GRU comparison

Authorized November3,2026. This is an offline residual MODEL experiment, not
a controller, hardware run or inverse-pressure deployment. The previous release
remains unchanged. NEXT_EXPERIMENT_PLAN.md in the parent defines the sequence.

The network takes observed q2,q3, causal estimated velocities, three commanded
pressures and previous physical sample interval. It outputs two generalized
forces in N. The same fixed corrected nonlinear nominal mechanics and SDIRK
integrator produce predicted lengths. No invented force/acceleration labels.

Primary state advances once per observed sample, carries through chronological
half-second chunks, and detaches between optimization updates. Independent
short free prediction starts from a COPY of the pre-current hidden state;
its q/v evolve through physics and its hidden state is discarded. Both GRU
layers keep separate explicit states. Segment/validity boundaries reset state.

October19/27 only: original whole-trial train/holdout labels and TRAIN-only
normalizer are unchanged. Common anchors require one second of available past
history and one second of future within a mature valid segment. Durations use
poll-start physical timestamps, not fixed frame counts. Selection uses .7 times
one-step vector RMSE plus .3 times .5s free-path vector RMSE, macro averaged
over eight eligible recordings. No day2 combined coverage; day2 step has only
two train chunks and no selection coverage. See data_20261103_v1/coverage.csv.

Six configurations: 1x32,1x64,2x32 with .5/1s auxiliary horizons. Common seed113,
Adam .0003, gradient clip1, batch32, maximum1200 updates, checkpoint every150,
patience4 after minimum600 updates. Loss independently averages normalized
one-step and free-path errors (weights .5/.5), plus force-rate .001 and force
magnitude .0001 regularization. The leading architecture gets a matched .5vs1s
burn-in test; replace only if older holdout improves. The leading two configs
then use seeds113,211,307; report all, with seed113 the fixed representative.

campaign_20261103_v2 retains predeclared protocol, all checkpoints, source
snapshots/hashes, scores and finalist model hashes. Incomplete v1 is preserved:
its first validation hit a variable-length force-bound reporting concatenation
error, fixed before v2. It has no released model and must not be used.

Only after FINALISTS_FROZEN.mat exists does sgExternal read November2 for all
finalist seeds. Previously inspected data are held-out evaluation, not blind
confirmation. Matched measured-state one-step and .1/.25/.5/1s free predictions,
coordinate errors/p95, phase/speed groups, force-rate/bounds and source hashes
are retained. No post-test refitting or selecting a lucky seed.

sgInverseCheck separately tests a pressure-dependent residual under fixed
common pressure, [0,3]bar bounds and 6bar/s at intended .05s (0.3bar/step).
Trial optimizer evaluations reuse unchanged pre-current state; only the chosen
command produces one committed state. Its targets are generated by the same
model, so this is self-consistency, NOT physical force or tracking validation.
Reported latency includes the bounded solve and selected inference, excludes
acquisition/control/real-time scheduling, and is not hardware qualification.

Entry points (repository root, add parent and this folder to MATLAB path):
